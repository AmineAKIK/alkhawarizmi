# Politique de sécurité

## Signaler une vulnérabilité

Merci de ne pas publier de vulnérabilité exploitable dans une issue publique.

Pour un signalement de sécurité, privilégier un canal privé et fournir autant que possible :

- la version ou le commit concerné ;
- les étapes minimales de reproduction ;
- l'impact observé ou potentiel ;
- toute proposition de correction ou de mitigation utile.

Les signalements peuvent être envoyés à `contact@akiksystems.com`.

## Périmètre

Cette politique couvre le code de l'application, sa chaîne de build, ses workflows d'intégration et de déploiement ainsi que les dépendances directement utilisées par le projet.

Les problèmes de contenu pédagogique sans impact de sécurité doivent être signalés via le système d'issues normal du dépôt.
